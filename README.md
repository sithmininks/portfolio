# Sithmini Sasanka – Personal Portfolio

A premium, modern personal portfolio website built with **React + Vite + Framer Motion**.

## 🚀 Tech Stack

- **React 19** – UI framework
- **Vite 8** – Build tool (lightning fast)
- **Framer Motion** – Professional animations
- **Lucide React** – Icon set
- **CSS Custom Properties** – Design system (no Tailwind dependency)

## ✨ Features

- 🌙 Dark / Light mode toggle
- ⌨️ Animated typing hero
- 🎭 Glassmorphism card design
- 🎨 Purple / electric blue / cyan gradient accents
- 📱 Fully responsive (mobile, tablet, desktop)
- 🖱️ Cursor glow effect (desktop)
- ♿ Reduced-motion accessibility support
- 🔝 Back-to-top button
- 📧 Contact form (demo mode)
- 🔍 SEO-optimised `<head>` metadata

## 📁 Structure

```
portfolio/
├── public/
│   └── favicon.svg
├── src/
│   ├── App.jsx        # All components in one file
│   ├── index.css      # Design system + all styles
│   └── main.jsx       # React entry point
├── index.html
├── vite.config.js
└── package.json
```

## 🛠 Development

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # Production build
npm run preview  # Preview production build
```

## 📦 Deployment

The `dist/` folder (after `npm run build`) can be deployed to:
- **Netlify** – drag & drop the `dist` folder
- **Vercel** – connect GitHub repo
- **GitHub Pages** – set `base` in `vite.config.js`
